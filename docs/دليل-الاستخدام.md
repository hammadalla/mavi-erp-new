# دليل استخدام برنامج Mavi — للمبتدئين

> **أهم حاجة الأول:** GitHub مكان بيحفظ الكود (زي جوجل درايف للمبرمجين). GitHub **مش بيشغّل** البرنامج.
> علشان تشغّل البرنامج على جهازك محتاج خطوتين: **تنزيل Node.js** (مرة واحدة) + **تشغيل ملف واحد**.
> التفاصيل تحت، ولو حبيت تنشره على الإنترنت بشكل دائم في الجزء الأخير.

---

## ١. اللي هتحتاجه (مرة واحدة بس)

| الحاجة | ليه | من فين |
|---|---|---|
| **Node.js** (نسخة LTS) | هو اللي بيشغّل البرنامج | <https://nodejs.org> — اضغط الزر الأخضر، Next → Install → Finish |
| **فولدر المشروع** | فيه كل الملفات | `mavi-erp/app` في مساحة العمل دي |
| **متصفح** (كروم / إيدج / سفاري) | للاستخدام اليومي | عندك أصلاً |

> متحتاجش تعرف برمجة. متحتاجش تنصّب قاعدة بيانات. متحتاجش إنترنت بعد التنصيب الأول.

## ٢. تشغيل البرنامج على جهازك — ٣ خطوات

### الطريقة السهلة (اللي بيفضّلها المبتدئين)

1. نزّل فولدر `app` كامل على جهازك (من مساحة العمل: اختار Download / نزّل المشروع).
2. **ويندوز:** دوس دبل كليك على `scripts/start-windows.bat`
   **ماك / لينكس:** دبل كليك على `scripts/start-mac-linux.command`
   *(أول مرة بس: لو الماك رفض يشغّله → كليك يمين → Open)*
3. استنى لحد ما تقرا في الشاشة `Mavi ERP → http://localhost:3000` — والمتصفح هيفتح لوحده.

> **سيب نافذة الشاشة السوداء مفتوحة** طول ما إنت بتستخدم البرنامج. لو قفلتها → البرنامج بيقف.
> علشان توقف البرنامج: اقفل النافذة أو اضغط `Ctrl + C`.

### الطريقة اليدوية (لو حبيت تفهم إيه اللي بيحصل)

افتح موجّه الأوامر (Command Prompt / Terminal) جوه فولدر `app` واكتب:

```bash
npm install          # تنزيل المكتبات — أول مرة بس
npm run seed         # تجهيز قاعدة البيانات وبيانات تجريبية
npm start            # تشغيل البرنامج
```

بعدها افتح المتصفح على:
- **لوحة الإدارة:** <http://localhost:3000/admin/>
- **واجهة العميلة:** <http://localhost:3000/store/>

`localhost:3000` معناها «البرنامج اللي شغّال على جهازي أنا، مش على الإنترنت».

## ٢.٥ دخول العميلات (مهم)
- العميلة بتعمل حساب بـ **الاسم + الموبايل + باسورد** — مفيش SMS ومفيش تكلفة.
- لو نسيت الپاسورد: كود على واتساب، ولو مفيش واتساب آلي إنتي تبعتيها الكود من
  **العميلات → كود الدخول**.
- عملاء الديمو باسوردهم `mavi1234`.

## ٣. الدخول — إيه الحسابات الموجودة

| الحساب | الإيميل | الباسورد | بيشوف إيه |
|---|---|---|---|
| **مالكة البراند** | `owner@mavi.eg` | `mavi-owner` | كل حاجة: الأوردرات + التكاليف + الأرباح + الفلوس |
| **مساعد التشغيل** | `staff@mavi.eg` | `mavi-staff` | الأوردرات والبورد والخامات — **من غير أي أرقام فلوس** |
| **العميلة** | أي رقم موبايل مصري | كود ٦ أرقام | طلباتها ومقاساتها بس |

> كود العميلة بيظهر على الشاشة في «وضع التجربة» وبيتطبع في نافذة السيرفر السوداء.
> في النسخة النهائية بيتبعت SMS أو واتساب (محتاج حساب في شركة إرسال رسائل).

**جرّب الاتنين** — ده بيوضّح نظام الصلاحيات: ادخل بـ `owner` وشوف صفحة «الفلوس»،
وبعدين خروج وادخل بـ `staff` — هتلاقي صفحة الفلوس اختفت ومكانها «التفاصيل المالية مش ظاهرة لحساب التشغيل».
ده مش زر مخفي، ده السيرفر نفسه مش بيبعت الأرقام للحساب ده.

## ٤. أول شغل حقيقي: إزاي تستخدمه في يومك

### كعميلة (من الموبايل)
1. افتح `/store/` → اختاري موديل من الكتالوج.
2. اختاري اللون والطول والعدد وطريقة الاستلام → **إرسال الطلب**.
3. أول مرة: تسجيل بالاسم والموبايل + **المقاسات** (مرة واحدة وبس).
4. بعد كده: كل طلب جديد بيتم في دقيقة، وتقدري تتابعي «طلباتي» بالشريط.

### كإدارة (شغل الورشة)
1. **لوحة التحكم** = نظرة الصبح: متأخر كام؟ إيه الجاهز للتسليم؟ خامات محتاجة شراء؟
2. **الأوردرات** → اضغط على أي أوردر:
   - بدّل الحالة من الشريط (جديد → مؤكد → قص → تفصيل → جاهز → تسليم) — **والرسالة العربية للعميلة بتتجهز لوحدها**، دوس «نسخ» وابعتها واتساب.
   - **كارت المقاسات** موجود جوه الأوردر — مفيش سؤال تاني للعميلة.
   - **ورقة الورشة**: دوس «طباعة / ورقة ورشة» → ورقة فيها المقاسات والخامة والورشة، ودّيها للورشة.
3. **بورد التفصيل** = مين شغال على إيه وامتى وعدها (القطعة المتأخرة عليها خط أحمر).
4. **الخامات والستوك** = القماش بالمتر؛ أول ما تسجّل خامة في أوردر، الأمتار بتنقص لوحدها.
5. **الفلوس** (للمالكة بس) = إيراد / محصّل / باقي عند العملاء / مصاريف / **صافي الربح**.
6. **التقارير** = أنهي موديل بيجيب فلوس، وأنهي ألوان بتتطلب أكتر (تشتري قماش الشهر الجاي على أساسه).

### أسرار صغيرة بتفرق
- **العربون:** تسجيل دفعة بيخصم من «الباقي» فورًا.
- **التكلفة:** متتحسبش غير لما تحدد الخامة (الأمتار) والورشة — قبل كده هتلاقي التكلفة صفر.
- **⚠️ قبل ما تستخدمه بجد:** غيّر باسوردات الحسابات، وشيل البيانات التجريبية بأمر `npm run reset` (بيسترجع نفس البيانات التجريبية) أو امسح ملف `data/mavi.db` واعمل `npm run seed` من جديد.

## ٥. إزاي تحافظ على الشغل ومتعملش غلطة

| القاعدة | ليه |
|---|---|
| **خد نسخة احتياطية كل يوم** — انسخ فولدر `data` كله (فيه ملف `mavi.db`) | كل بياناتك في الملف ده. لو ضاع، ضاع كل حاجة |
| **سيب نافذة السيرفر مفتوحة** | قفلها = البرنامج وقف |
| **متشغّلش نسختين على نفس الملف** | ممكن يتعارضوا |
| **متعملش `npm run reset`** إلا لو عايز تمسح كل حاجة وتبدأ من الأول | بيمسح الأوردرات والعملاء |
| **متغيّرش ملفات `src/`** إلا لو فاهم | ده كود البرنامج |

نسخة احتياطية احترافية = تنسخ فولدر `data` على فلاشة أو جوجل درايف كل يوم قبل ما تقفل.

## ٦. GitHub — إيه دوره بالظبط وإمتى تحتاجه

### الفكرة في سطر واحد
**GitHub = خزنة كود + تاريخ للتغييرات.** مفيد علشان: تحتفظ بنسخة آمنة، تشتغل مع مطوّر تاني، وتنشر على استضافة.

### هل لازم تستخدمه علشان تشغّل البرنامج؟ **لأ.**
البرنامج بيشتغل على جهازك من غير GitHub خالص.

### إمتى تحتاجه؟
1. **عايز تحتفظ بنسخة على الإنترنت** (لو اللابتوب باظ).
2. **عايز تفتح البرنامج من أكتر من جهاز** (بيت + محل).
3. **عايز تنشره على الإنترنت** للعميلات — الاستضافة (Vercel / Render / Railway) بتسحب الكود من GitHub.
4. **هتشتغل مع مطوّر** بعدين.

### إزاي ترفعه على GitHub (خطوات للمبتدئ)
1. اعمل حساب على <https://github.com> (مجاني).
2. نزّل **GitHub Desktop** من <https://desktop.github.com> — واجهة بالماوس، من غير أوامر.
3. في البرنامج: `File → Add Local Repository` → اختار فولدر `app`.
4. لو قالك «not a git repository» → اضغط `create a repository`.
5. اكتب رسالة قصيرة (مثلاً «أول نسخة») → اضغط **Commit to main** → بعدها **Publish repository**.
6. خلاص — الكود على GitHub. أي تعديل بعد كده: Commit ثم Push.

### اللي **متعملش** رفعه على GitHub
- ملف `data/mavi.db` (فيه بيانات عملائك) — موجود في `.gitignore` بالفعل، سيبه.
- أي باسوردات حقيقية.

### تنبيه مهم
GitHub **مش** بيشغّل البرنامج. لو حد فتح اللينك بتاع الريبو مش هيلاقي برنامج شغّال — هيلاقي الكود بس.

## ٧. تنشره على الإنترنت (علشان العميلات يفتحوه من موبايلهم)

البرنامج ده **سيرفر** (محتاج يشغّل ٢٤ ساعة)، فمش هينفع على «استضافة مواقع عادية». الخيارات:

| الخيار | مناسب لمين | التكلفة التقريبية | ملاحظة مهمة |
|---|---|---|---|
| **Render** أو **Railway** | الأسهل للمبتدئ | مجاني للتجربة، ~$5–7/شهر للجد | بياخد الكود من GitHub ويشغّله لوحده |
| **VPS** (Hetzner / DigitalOcean) | لو عايز تحكم كامل | ~$5/شهر | محتاج شوية إعداد |
| **Vercel** | ⚠️ مش الأنسب هنا | مجاني | Vercel ممتاز للواجهات، لكن الملفات (SQLite) مش بتتحفظ فيه — محتاج قاعدة بيانات خارجية |

**أسهل طريق دلوقتي:** ارفع على GitHub → اعمل حساب على **Render** → `New → Web Service` → اختار الريبو →
Start Command: `npm start` → بعد ما يخلص هيديك لينك زي `mavi-erp.onrender.com`.

⚠️ **قبل النشر على الإنترنت لازم:**
1. تغيّر باسوردات الحسابات.
2. توصّل إرسال كود العميلة الحقيقي (SMS/واتساب) وتخلي `SHOW_OTP=0`.
3. تنسخ `data/mavi.db` على قرص دائم (Persistent Disk) — وإلا البيانات تتمسح مع كل تحديث.
4. تعمل نسخ احتياطي تلقائي.

## ٨. حل المشاكل الشائعة

| المشكلة | الحل |
|---|---|
| `node is not recognized` | Node.js مش متنصّب أو محتاج تقفل النافذة وتفتحها من جديد بعد التنصيب |
| `npm install` بيفشل | اتأكد من الإنترنت، وجرّب تاني. لو لسه: امسح فولدر `node_modules` وجرّب |
| الصفحة مش بتفتح | السيرفر مش شغّال (النافذة السوداء مقفولة) — شغّله تاني |
| `EADDRINUSE` / البورت مشغول | في نسخة قديمة شغّالة — اقفلها، أو شغّل ببورت تاني: `PORT=3001 npm start` |
| نسيت الباسورد | مفيش شاشة استرجاع — استخدم حساب `owner`، أو امسح `data/mavi.db` واعمل `npm run seed` (هيمسح البيانات) |
| الأرقام المالية مش ظاهرة | إنت داخل بحساب `staff` — ده مقصود. ادخل بحساب `owner` |
| عايز أبدأ من الأول | `npm run reset` |
