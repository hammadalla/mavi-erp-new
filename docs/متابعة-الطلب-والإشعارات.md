# تسجيل المقاسات ومتابعة الطلبات

## قبل إرسال تصميم خاص
1. تفتح العميلة واجهة المتجر وتسجل حسابًا أو تدخل إلى حسابها.
2. من «بياناتي»، تحفظ اسمها والمقاسات الأساسية: الصدر، الوسط، الهيب والطول. مقاس الكم والذراع اختياريان.
3. تعود إلى «الكتالوج» وتفتح «عندكِ تصميم مختلف؟». تختار صورة التصميم وتضيف موعدًا أو ملاحظة إن رغبت.
4. عند الإرسال يحفظ البرنامج نسخة من المقاسات الموجودة وقت الطلب؛ لا يطلب إدخالها مرة أخرى. يمنع الخادم الإرسال إذا لم تكتمل البيانات المطلوبة، حتى لو استُخدمت طريقة غير الواجهة.

## تحديث حالة الفستان
1. بعد تحديد السعر ورفع الإيصال وتأكيد الإدارة استلام العربون، يتحول طلب التصميم إلى أوردر.
2. من «الأوردرات»، تفتح الإدارة الأوردر وتختار المرحلة: تأكيد، قص، خياطة، جاهز أو تسليم.
3. تظهر المرحلة الجديدة في «طلباتي» لدى صاحبة الطلب، ويُحفظ إشعار داخل حسابها. إذا ظلت الصفحة مفتوحة، تتحقق من التحديثات كل ١٥ ثانية تقريبًا أثناء ظهورها. قد يتأخر العرض بحسب الاتصال والمتصفح.
4. يمكن للعميلة تحديد الإشعارات كمقروءة؛ لا يطلع عليها حساب عميلة أخرى. تبقى الإشعارات في قاعدة البيانات طالما بقيت محفوظة.

## واتساب
بعد تغيير الحالة، تظهر رسالة جاهزة للإدارة. زر «فتح واتساب للعميلة» يفتح المحادثة بالرسالة لتراجعها الإدارة وتضغط إرسال بنفسها. لا تُرسل أي رسالة تلقائيًا، ولم تُضف إشعارات خارجية أو تنبيهات هاتف عندما يكون الموقع مغلقًا.

## المعاينات والتشغيل
ملف HTML نموذج مستقل غير مرتبط بقاعدة البيانات أو واتساب حقيقي؛ التسجيل والإشعارات فيه للتجربة فقط وقد تُفقد عند إغلاقه. التطبيق الحقيقي يحتاج خادمًا وقاعدة بيانات دائمة ونسخًا احتياطية. بيانات الدخول التجريبية المعروفة يجب تغييرها قبل النشر الحقيقي. تطبيق APK السابق غلاف للموقع، ولن يتحدث البرنامج المنشور تلقائيًا بمجرد تنزيل هذه الملفات.
