# التصميم الخاص والحذف والذاكرة

## طلب التصميم الخاص
تختار العميلة صورة إلى ١٠ صور مرجعية (كل صورة JPG أو PNG أو WebP بحد أقصى ٢ ميجابايت)، وتكتب اللون والخامة المطلوبين، وتختار قماش MAVI أو قماشها الخاص والمحافظة. تُستخدم مقاساتها المحفوظة. يظهر للمالكة الطلب والصور والتفاصيل داخل قسم الطلبات. تُرفع الصور الإضافية واحدة بعد الأخرى لتقليل ذروة الذاكرة؛ إذا فشل رفع بعض الصور بعد تسجيل الطلب، يُعرض تنبيه للعميلة للتواصل مع البراند لإرسال الصور المتبقية. لا تعيدي تقديم الطلب قبل التأكد منه.

## الحذف النهائي — للمالكة فقط
زر الحذف داخل القسم المتعلق بالسجل، مثل الموديل والخامة والطلب وطلب التصميم والعميلة والمصروف والدفعة. يعرض البرنامج أثر الحذف ويطلب كلمة مرور المالكة وعبارة «حذف نهائي». حذف العميلة يحذف طلباتها وطلبات تصميمها وصورها ومقاساتها ودفعات الطلبات؛ وحذف طلب يحذف دفعاته والإيصالات والإشعارات وطلب التصميم المرتبط إن وُجد. ستتغير التقارير. الحذف لا يرد أموالًا ولا يعيد أرصدة القماش أو المخزون تلقائيًا؛ راجعيها يدويًا. بعض السجلات المرتبطة، مثل موديل أو خامة مستخدمة في طلب، لا يمكن حذفها قبل السجلات المرتبطة. دفعة العربون المؤكد لا تُحذف بمفردها لأنها مرتبطة بحالة الطلب. لا توجد أزرار لحذف كل جداول النظام أو حساب المالكة أو سجل التدقيق.

نزّلي نسخة احتياطية واختبري إمكانية استعادتها قبل الحذف. ملفات النسخ الاحتياطية تحتوي بيانات شخصية ويجب حفظها في مكان آمن. حذف السجل من قاعدة البيانات الحالية لا يحذفه من النسخ الاحتياطية السابقة، ولا يضمن إزالة آثار البايتات من ملف SQLite أو وسائط التخزين على مستوى الطب الشرعي.

## موارد الخطة المجانية
استُخدم حد ٦٤ ميجابايت لذاكرة JavaScript في Docker (ليس حدًا لاستهلاك العملية كلها)، وحد مستهدف ٢ ميجابايت لذاكرة صفحات SQLite، وتُسمح عملية رفع صورة كبيرة واحدة في المرة. عند وجود رفع آخر قد تظهر رسالة تطلب المحاولة لاحقًا. تجنّب الاستعلامات غير الضرورية لبيانات الصور يقلل الذروة؛ لا يوجد ضمان بالعمل دائمًا تحت ١٢٨ ميجابايت، خاصة مع تزامن الزوار أو زيادة البيانات.

قياس محلي على Node 20 وببيانات تجريبية: نحو ٥٦ MiB عند بدء التشغيل وذروة ٨٥ MiB تقريبًا خلال ثلاث صور بحجم ١٫٩ MB رُفعت بالتتابع. هذا ليس اختبارًا تحت ضغط حقيقي ولا قياسًا من Deplexo، وقد يختلف الاستهلاك والمجموع المحتسب على الاستضافة. راقبي استهلاك الذاكرة والقرص وجرّبي الموقع تدريجيًا. الصور مخزنة في قاعدة البيانات وتستهلك حجم القرص المحدود؛ ضغط الصور قبل رفعها وتجنّب الصور غير الضرورية يساعدان. النسخ الاحتياطي يحتاج أيضًا مساحة مؤقتة كافية.

يجب التأكد من أن `/data` قرص دائم ومهيأ للكتابة، وأن قاعدة البيانات تبقى بعد إعادة النشر. لا تُشارك بيانات حقيقية قبل التحقق من التخزين والنسخ الاحتياطي والاستعادة.
